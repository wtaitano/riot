ckm: conditional kinetic miniapp
================================

ckm is a standalone `Parthenon <https://github.com/parthenon-hpc-lab/parthenon>`_
application for conditional kinetic modelling with block-AMR tensor trains. It lives
in the ``conditional_kinetic_miniapp/`` directory of the riot repository but shares no
source or build with riot. It uses the tensor-train branch of Parthenon (`PR #1464
<https://github.com/parthenon-hpc-lab/parthenon/pull/1464>`_), pinned in
``external/parthenon``.
