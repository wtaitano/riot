# Plan histories (ckm)

Place generative-AI plans for ckm changes in this folder, following riot's
[AI-assisted coding policy](../../doc/sphinx/src/contributing.rst).

ckm is developed through internal PRs on the `wtaitano/riot` fork, with one final PR
into `lanl/riot`. Name each file after the **internal fork PR number**:
`ckm-fork-pr-<N>.md`. Before the PR number is known, use a descriptive name and
rename it once the PR is open. The final `lanl/riot` PR description lists these
files.
